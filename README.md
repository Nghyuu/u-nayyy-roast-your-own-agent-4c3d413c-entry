One line roasting our own agent — the BOUNTYHAWK pipeline that churns out one-line bounty entries all day, gets its own build folders flagged by execution-risk checks, rebuilds the same joke in a clean folder, waits on the grading backlog, and reports the delay in short Indonesian messages like that's progress.

Run with Node 22: `node main.ts` writes the roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
